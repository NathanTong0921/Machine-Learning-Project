# Project Handout

## Project Purpose

This project studies the UCI student dropout and academic success dataset. It builds a full machine learning workflow for predicting student status: `Dropout`, `Enrolled`, or `Graduate`.

The repository contains data preparation, classical baselines, tuned tree models, neural tabular models, result summaries, and supporting course/report materials.

## Core Source Modules

| Module | Main Responsibility |
| --- | --- |
| `src/config.py` | Central paths, target label, random seed, class labels, categorical columns, and feature groups. |
| `src/data_utils.py` | Loads the raw dataset from `data/raw/data.csv`. |
| `src/preprocessing.py` | Builds the shared scikit-learn preprocessing pipeline for numeric and categorical features. |
| `src/baselines.py` | Defines classical baseline models and their search spaces. |
| `src/clustering.py` | Defines clustering models and clustering evaluation helpers. |
| `src/evaluation.py` | Computes classification metrics, detailed reports, confusion matrices, and saves metric tables. |
| `src/visualization.py` | Saves confusion matrix plots, metric table figures, and figure grids. |
| `src/advanced_models.py` | Implements PyTorch tabular models, dataloaders, training loops, and prediction helpers. |
| `src/train.py` | Minimal placeholder for future training entry points. |

## Advanced Model Implementations

`src/advanced_models.py` contains the neural tabular model family:

| Component | Function |
| --- | --- |
| `MultiViewGatedMLP` | Splits features into semantic views, encodes each view, and learns gates for view fusion. |
| `TabMStyleMultiExpertMLP` | Multi-expert MLP inspired by TabM-style expert aggregation. |
| `FTTransformer` | Transformer-based model for categorical and numerical tabular features. |
| `PiecewiseFTTransformer` | FT-Transformer variant with piecewise numerical feature tokenization. |
| `ViewAwareFTTransformer` | FT-Transformer variant with feature-view awareness. |
| `ViewWiseGatedFTTransformer` | View-wise transformer with learned gates across feature groups. |
| `ViewWiseAttentionGatedFTTransformer` | Attention-pooled gated transformer variant. |
| `TromptStylePromptTransformer` | Prompt-style tabular transformer inspired by Trompt-like modeling. |

The same module also provides:

| Helper | Function |
| --- | --- |
| `prepare_multiview_data` | Builds train/validation/test view matrices for multi-view models. |
| `prepare_ft_transformer_data` | Builds categorical/numerical tensors for FT-style models. |
| `create_dataloaders` | Creates dataloaders for multi-view models. |
| `create_ft_dataloaders` | Creates dataloaders for FT-style transformer models. |
| `train_*` functions | Train each advanced model and return predictions, probabilities, histories, and metadata. |
| `predict_*` functions | Run inference for each advanced model family. |

## Typical Workflow

1. Prepare data:

```bash
python scripts/preprocessing/prepare_data.py
```

2. Run baseline models:

```bash
python scripts/baseline/run_baselines.py
python scripts/boost/run_lightgbm_baseline.py
python scripts/boost/run_catboost_baseline.py
```

3. Run tuned models:

```bash
python scripts/boost/tune_catboost_baseline.py
LIGHTGBM_N_JOBS=108 python scripts/boost/tune_lightgbm_baseline.py
```

4. Run advanced model comparisons:

```bash
python scripts/transformer/compare_advanced_models.py
python scripts/transformer/compare_viewwise_gated_transformers.py
```

5. Summarize results:

```bash
python scripts/reporting/summarize_results.py
python scripts/reporting/summarize_primary_contenders.py
```

## Notes For Handoff

- The repository tracks source code, docs, raw data, and compact metric files.
- Generated model checkpoints, figures, logs, and intermediate processed data are ignored by Git.
- Most scripts should be run from the repository root.
- The shared constants in `src/config.py` should be updated first if paths, labels, or feature groups change.
