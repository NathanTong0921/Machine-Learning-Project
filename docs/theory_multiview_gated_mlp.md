# Theory Mainline for Multi-View Gated MLP

## Target

要解释的现象是：

- 学生结局预测不是由单一特征块决定，而是由多个信息视图共同决定。
- 不同学生对不同视图的依赖强度不同，因此固定权重融合往往不够。

要支持的主张是：

- `Multi-View Gated MLP` 可以被理解为一种 **样本自适应的多视图风险最小化模型**。
- 门控层学习的不是“哪个视图永远最重要”，而是“对当前样本，哪个视图应被赋予更高权重”。

这份说明的目标是 **机制解释与公式主线**，不是严格定理证明。

## Invariant Object

选择统一对象为期望分类风险：

\[
\mathcal{R}(f) = \mathbb{E}_{(x,y)\sim \mathcal{D}}[\ell(f(x), y)].
\]

这里：

- \(x = (x^{(1)}, x^{(2)}, x^{(3)}, x^{(4)})\) 表示四个视图
- \(y \in \{\text{Dropout}, \text{Enrolled}, \text{Graduate}\}\)
- \(\ell\) 是多分类交叉熵

整个理论线都围绕“如何构造一个更合适的 \(f(x)\) 来降低风险”展开。

## Assumptions and Notation

将输入拆成四个视图：

1. \(x^{(1)}\)：入学与人口学背景
2. \(x^{(2)}\)：家庭与经济背景
3. \(x^{(3)}\)：第一学期表现
4. \(x^{(4)}\)：第二学期表现与宏观变量

令每个视图先经过一个编码器：

\[
h_i = \phi_i(x^{(i)}), \quad i=1,2,3,4,
\]

其中 \(h_i \in \mathbb{R}^d\)。

再定义门控网络：

\[
g(x) = \mathrm{softmax}(W_g [h_1;h_2;h_3;h_4] + b_g),
\]

其中 \(g(x) = (g_1(x), \dots, g_4(x))\)，满足：

\[
g_i(x)\ge 0, \qquad \sum_{i=1}^4 g_i(x)=1.
\]

## Main Derivation

### Step 1: 多视图表示

每个视图单独提取信息：

\[
h_i = \phi_i(x^{(i)}).
\]

这一步的含义是把 heterogeneous tabular features 先转成同维度表示，避免不同视图直接混合后丢失结构。

### Step 2: 样本自适应融合

定义融合表示：

\[
z(x) = \sum_{i=1}^4 g_i(x) h_i.
\]

这一步是一个 **凸组合**。因此：

\[
z(x) \in \mathrm{conv}\{h_1, h_2, h_3, h_4\}.
\]

解释上，这意味着最终表示不是固定选一个视图，而是在当前样本上对多个视图进行软选择。

### Step 3: 分类器

分类输出写成：

\[
\hat{y} = \psi([h_1;h_2;h_3;h_4;z(x);g(x)]).
\]

这里保留：

- 各视图的局部表示 \([h_1;h_2;h_3;h_4]\)
- 融合表示 \(z(x)\)
- 门控权重 \(g(x)\)

因此模型既保留“局部证据”，也保留“融合决策”。

### Step 4: 风险最小化

经验风险写成：

\[
\hat{\mathcal{R}}(f)=\frac{1}{n}\sum_{j=1}^n \ell(f(x_j), y_j).
\]

训练过程本质上是求解：

\[
\min_{\{\phi_i\}, g, \psi} \hat{\mathcal{R}}(f) + \lambda \Omega(f),
\]

其中 \(\Omega(f)\) 表示 dropout、weight decay 等正则化对应的复杂度控制。

## Mechanism Interpretation

如果某个样本的第二学期表现非常强，那么门控网络可能给出：

\[
g_4(x) \gg g_1(x), g_2(x), g_3(x).
\]

这表示模型认为“近期学业表现”对该样本最有判别力。

如果某个样本早期成绩信号弱，但入学背景和财务状态异常明显，则门控可以把更多权重分配给 \(x^{(1)}\) 和 \(x^{(2)}\)。

因此该模型对应一种机制：

- 不是所有学生共享同一套固定特征重要性；
- 特征重要性本身是样本依赖的；
- 门控层学习的是这种样本条件下的视图选择规律。

## Why This Can Beat a Flat Model

若使用平铺模型：

\[
f_{\text{flat}}(x)=\psi([x^{(1)};x^{(2)};x^{(3)};x^{(4)}]),
\]

则所有信息在一开始就被混合，模型难以显式表达“对这个样本，视图 4 更重要；对另一个样本，视图 1 更重要”。

而 `Multi-View Gated MLP` 引入了显式权重：

\[
z(x)=\sum_i g_i(x)h_i.
\]

于是模型容量的一部分被专门用于学习 **跨视图的条件性重要性**，这就是它相对普通 MLP 的主要结构优势。

## Relation to the Current Empirical Result

当前实验的 gate summary 显示：

- `second_semester_macro` 在三类样本上都占主导

这与理论机制一致，说明：

- 学业后期表现包含最高密度的判别信号；
- 门控层自动把主要权重放到最有预测力的视图上；
- 同时保留其他视图，避免完全丢掉背景信息。

## Scope and Non-Claims

这条理论线支持的，是下面这些说法：

- 多视图分解对这类学生表格数据是合理建模方式
- 门控融合可以表达样本依赖的视图重要性
- 经验上观察到的 gate 分布与模型设计目标一致

这条理论线 **不支持** 下列过强表述：

- 该模型必然优于所有树模型
- gate 权重等于严格因果贡献
- 第二学期视图主导就说明其他视图不重要

## 可直接写进报告的短版结论

`Multi-View Gated MLP` 可被视为一个样本自适应的多视图分类器。它先对不同信息块分别编码，再通过 softmax 门控学习每个样本上的视图权重，并以加权融合表示完成预测。该结构允许模型显式表达“不同学生依赖不同信息源”的规律，因此比固定融合或平铺式 MLP 更适合本数据集这类具有天然分块结构的表格问题。
